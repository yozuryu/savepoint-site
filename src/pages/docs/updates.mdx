<div class="codebox"><pre><span class="k">git remote add</span> template https://github.com/yozuryu/savepoint.git{'\n'}<span class="k">git fetch</span> template{'\n'}<span class="k">git merge</span> template/main --allow-unrelated-histories   <span class="c"># first time; later just git merge template/main</span></pre></div>

<p class="muted">When Git reports conflicts in your config or series files, keep your own version.</p>
