<div class="tbl"><table>
<thead><tr><th>When</th><th>Mode</th><th>What it does</th></tr></thead>
<tbody>
<tr><td>Every hour</td><td><code>incremental</code></td><td>Recent activity; writes only when you played or unlocked something</td></tr>
<tr><td>Daily, 00:05 UTC</td><td><code>midnight</code></td><td>Rarity, ranks and other slow-changing data</td></tr>
<tr><td>By hand</td><td><code>full-refresh</code></td><td>Every game on every platform: the first run, or a repair</td></tr>
<tr><td>By hand</td><td><code>watchlist-only</code></td><td>Only the RetroAchievements want-to-play list</td></tr>
</tbody>
</table></div>

To start one by hand, open **Actions → Fetch Data → Run workflow** in your repository and pick the mode.
