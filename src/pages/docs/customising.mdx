- **Fallback art**: after your first run, `npm run build:fallback-art` builds the mosaic shown behind games without art from your own library.
- **Custom domain**: **Settings → Pages → Custom domain**. Every page works at any address.
- **Looks**: plain files, no build step. Shared styles are in `assets/ui.css`; edit, push, done.
- **README posters**: `npm run posters` makes the images in your README from screenshots of your own site.
