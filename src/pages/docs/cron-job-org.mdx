## 1. Create a GitHub token

Make a <a href="https://github.com/settings/personal-access-tokens/new" target="_blank" rel="noopener">fine-grained token</a> with **Only select repositories** → <code><Fill client:idle k="repo" /></code>, and **Permissions → Actions: Read and write**.

## 2. Create the job

On <a href="https://cron-job.org" target="_blank" rel="noopener">cron-job.org</a>, create a job with these settings. The URL fills in from the name you gave on the <a href="../">setup page</a>.

<CronHelper client:visible />

<p class="muted">Make one job of each kind. A working call answers <code>204 No Content</code>. You can keep the built-in schedule as a fallback or remove its <code>cron:</code> lines from <code>fetch-data.yml</code>.</p>
